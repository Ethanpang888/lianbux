3. 计划上只写"4×8"，怪不得你练不出形状

**正文**

先说一个扎心的事实：你手里的计划，99% 缺了最关键的一行——**每个动作练多重**。

「卧推 4×8」谁都会写。问题是：4×8 用 40kg 练和用 60kg 练，是两个完全不同的训练。

✅ 新手为什么长得慢：不是动作不会，是**重量全靠猜**——今天心情好加一片，明天疼了减两片，身体根本不知道你要它变强

✅ 网上抄的计划为什么没用：那是**别人的重量**。他 78kg 练 5 年推 80，你 62kg 刚练 3 个月抄他的？直接废

✅ 正确的打开方式：你的计划上应该写着——按你的体重和经验，每个动作今天该上多少 kg，做满次数之后加多少，什么时候减载

我自己做了个工具解决这个问题：填身高体重目标 → 每个动作的重量直接算出来（精确到 2.5kg），练完打卡，它还跟着你的进步自己调。
