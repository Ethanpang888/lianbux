# 个人定制 · 减脂塑形训练与饮食计划（女生版）

> 交付底稿（示例客户：女 26 岁 160cm/55kg 减脂塑形）。出售时按买家信息替换，结构不变。

## 一、你的基本情况

| 项目 | 内容 |
|---|---|
| 性别 / 年龄 | 女 / 26 岁 |
| 身高 / 体重 | 160cm / 55kg |
| 困扰 | 体重不重但腰腹松、臀线塌、大腿内侧肉多 |
| 可训练时间 | 晚上每周 3 次 + 周末偶尔 |
| 训练经验 | 跟练过视频课程，没系统练过器械 |
| 饮食现状 | 外卖为主，奶茶每周 2–3 杯 |
| 目标 | 减脂塑形：腰腹紧致、臀线上提、手臂变细不想要"块" |

## 二、总体思路

先说三颗定心丸：

1. **女生练器械不会变"块"**——女性睾酮水平决定了长肌肉比男生难得多，你看到的那种块是十年级的专业选手；
2. **塑形靠力量训练，不是靠跑步**——跑步瘦下来是"小一号的自己"，力量训练才是"换个形状"；
3. **体重秤会说谎**——女生体重受生理期影响一周能波动 1–2kg，这份计划看的是**周平均 + 腰围 + 照片**，不是每天的情绪秤。

计划结构：**热量小缺口 + 臀腿优先的力量训练 + 少量有氧**。

## 三、饮食方案

### 1. 每天吃多少

| 项目 | 数值 | 依据 |
|---|---|---|
| 每日热量 | **1450 kcal** | 比消耗低约 300 的温和缺口——"微微饥饿"就够了，饿到心慌就是开大了 |
| 蛋白质 | **88g**（1.6g/kg） | 取 1.4–1.8 区间中值——保住肌肉，塑形才有"紧"的感觉 |
| 碳水 | **175g**（3.2g/kg） | 落在 2.2–3.5 区间内，训练有劲 |
| 脂肪 | **44g**（0.8g/kg） | 不低于 0.8——女生脂肪吃太少会直接影响生理期 |
| 饮水 | **2L/天** | 训练日加 0.5L |

> ⚠️ **生理期不称重、不对比**（波动 1–2kg 是水分不是脂肪）。每月只对比同一周期的数据。

### 2. 一天怎么排

| 餐次 | 吃什么 | 大约 |
|---|---|---|
| 早餐 | 鸡蛋 2 个 + 无糖豆浆/酸奶 + 全麦面包 1 片 + 蓝莓一把 | 350 kcal |
| 午餐 | 杂粮饭 150g + 去皮鸡腿肉/鱼虾 120g + 绿叶菜一大份 | 450 kcal |
| 下午加餐 | 无糖酸奶 / 水煮蛋 1 个 / 小番茄 | 100 kcal |
| 晚餐（练后） | 米饭 100g + 瘦肉/豆腐 100g + 蔬菜一大份 | 400 kcal |
| 想吃甜的 | 放到练后吃，算进总量——控制总量比禁止食物更可持续 | 150 kcal 以内 |

**外卖同减脂版 6 条规则**：去皮瘦肉、蔬菜过水、酱汁最后剩、奶茶换成"每周 1 次解馋餐后"。

### 3. 补剂

| 补剂 | 吃法 | 说明 |
|---|---|---|
| 乳清蛋白 半勺–1 勺 | 蛋白没够的餐后 | 88g 靠日常不容易，蛋白粉是女生最容易缺的一环 |
| 维生素 D₃ | 早晨 1 粒 | 室内工作者普遍缺 |
| 铁/复合维生素 | 随餐（可选） | 生理期量大或素食倾向者考虑，先咨询医生 |

## 四、训练方案

### 1. 结构与原则

- 每周 3 练：**臀腿日 / 背臂日 / 肩胸日**，中间休息（如周二/周四/周六）；
- **臀腿是主战场**：每周直接练臀腿 1 次全量的，其余两天也带 1–2 个臀部动作；
- 组间休息：主项 2–3 分钟、孤立 1–1.5 分钟；
- 每次**力量练完加 20 分钟有氧**（快走坡度/椭圆机/爬楼，不跑长距离——跑步掉臀腿肌肉，塑形期做低冲击有氧）。

### 2. 重量自测 —— 第一次训练先做（重要）

跟男生版同一条规则：**你的重量你测出来**，10 分钟：

1. 从最轻开始 → 做满 12 次，轻松就加一点（+1–2.5kg）→ 再来；
2. 直到**能标准做满 12 次、最后 2 次有点勉强、不变形**；
3. 填进表里，之后递进全以你填的数为基准；
4. 安全线：做不满 8 次或变形，退一档。

**别怕重**：腿举蹬 60kg 你也不会变金刚芭比，只会变翘臀。

### 3. 怎么往上加（塑形也要加重！）

同一个重量：做满 3×12 → 3×15 → **加 1–2.5kg**，回到 3×12 重新爬。**臀想翘、背想薄，唯一的路就是重量慢慢涨**——一直拿粉色小哑铃晃，练一年也是老样子。

**减载**：每 4 周安排 1 周，组数砍半、重量维持。生理期前后的低状态周，自动当成减载周用。

### 4. 有氧

- 力量练完 20 分钟：快走（坡度 8–10）/ 椭圆机 / 爬楼机，选一个；
- 不推荐长距离跑步——消耗肌肉、膝盖负担大，塑形期性价比低；
- 日常多走路比什么都有用：每天 8000 步是底线。

## 五、睡眠与恢复

- 23:30 前睡——熬夜掉的是肌肉留的是脂肪，塑形大忌；
- 睡前 4 小时不喝奶茶/咖啡（咖啡因代谢女生偏慢）；
- 生理期前 3 天状态差是正常的：把那几天自动按"减载周"处理，不硬撑。

## 六、执行清单

- **每天**：晨起空腹称重（生理期跳过）→ 按克数吃 → 走够 8000 步；
- **每周**：量**腰围 + 臀围**（塑形期这两个比体重重要）→ 看 7 天平均；
- **每两周**：穿运动内衣+短裤拍正面/侧面照，对比腰线与臀线；
- **每月**：对比同一个生理周期——跨周期对比才有意义。

## 七、说明

- 本计划为训练与营养参考，不构成医疗建议；孕期哺乳期、生理紊乱、用药情况，先咨询医生；
- 执行 4 周后带数据回来，按实际变化出下一版；
- 数字口径：宏量区间参考谭成义的减脂体系；组次递进与减载为训练通用规律；"常见范围"由体重数据推演，仅供起点参考——**最终以你自测的重量为准**。
