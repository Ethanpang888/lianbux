# 个人定制 · 增肌训练与饮食计划

> 交付底稿（示例客户：男 24 岁 178cm/62kg 偏瘦增肌）。出售时按买家信息替换全档数字，结构不变。

## 一、你的基本情况

| 项目 | 内容 |
|---|---|
| 性别 / 年龄 | 男 / 24 岁 |
| 身高 / 体重 | 178cm / 62kg |
| 体型 | 偏瘦，怎么吃都不胖 |
| 可训练时间 | 下午 / 傍晚，每周 3–4 次 |
| 训练经验 | 系统训练约 1 年，动作都会但没系统加过重量 |
| 饮食现状 | 食堂为主，胃口一般，吃不下特别大的量 |
| 作息 | 24 点前睡，约 7.5 小时 |
| 目标 | 增重增肌，先涨到 68–70kg |

## 二、总体思路

瘦人增肌，**第一难关不是练，是吃**。你的消耗不小、胃口又一般，热量常年刚好打平——体重自然不动。所以这份计划的优先级排得很清楚：

1. **吃够**：热量比消耗多约 200（凯圣王的增肌热量口径），用加餐解决"吃不下"；
2. **练重**：动作都会了，缺的是**每次都记录、每次都进步**——所以这份计划的核心是一张自测重量表和一条加重规则；
3. **睡够**：你睡眠底子不错，保持；
4. **耐心**：自然增肌一个月涨 0.5–1kg 体重就是优秀进度，涨太快涨的都是肚子。

## 三、饮食方案

### 1. 每天吃多少

| 项目 | 数值 | 依据 |
|---|---|---|
| 每日热量 | **2450 kcal** | 消耗 + 约 200 盈余（凯圣王《卧推系列⑩饮食》：训练日 = 代谢 + 消耗 + 200） |
| 蛋白质 | **100g**（1.6g/kg） | 谭成义区间 1.2–2.0 的中值；够用就好，吃太多也是浪费 |
| 碳水 | **375g** | 谭的 2.5–3.5 倍体重是**起步值**——偏瘦体质要往上加，瘦人吃到这个量是正常的 |
| 脂肪 | **50g**（0.8g/kg） | 取谭 0.6–0.8 上限，热量不够脂肪来补 |
| 饮水 | **2.5L/天** | 训练日加 0.5L |

> 检验标准只有一个：**每周晨起空腹称重，周均涨 0.2–0.5%**（62kg 即每周 +0.15~0.3kg）。涨慢了加碳水 30g，涨太快减 30g。

### 2. 吃不下怎么办（瘦人增肌的关键）

一日三餐塞不下 2450，就拆成 **3 正餐 + 2 加餐**：

| 餐次 | 吃什么 | 大约 |
|---|---|---|
| 早餐 | 燕麦 80g + 鸡蛋 2 个 + 牛奶 300ml | 600 kcal |
| 上午加餐 | 面包 2 片 + 花生酱 + 香蕉 | 400 kcal |
| 午餐 | 米饭 250g + 大荤（鸡腿/牛肉/鱼）+ 蔬菜 | 700 kcal |
| 练前 1 小时 | 香蕉 1 根 + 面包 1 片 | 250 kcal |
| 晚餐（练后） | 米饭 200g + 蛋白主菜 + 蔬菜 + 牛奶 | 500 kcal |

**液体热量是你的朋友**：牛奶、豆浆、蛋白粉燕麦糊——喝下去比嚼下去容易得多。

### 3. 蛋白怎么微调（谭的"放屁信号"）

蛋白从 100g 起步，观察身体反应：**放屁又多又臭 → 减 10–20g；没有 → 保持或加 10g**。这是谭成义的原话方法，简单粗暴但好用。

### 4. 补剂

| 补剂 | 吃法 | 说明 |
|---|---|---|
| 一水肌酸 5g | 每天 1 勺，长期 | 力量补剂里证据最足的，瘦人增力的第一优先 |
| 乳清蛋白 1–2 勺 | 加餐/练后 | 蛋白吃不够时用，别当饭 |
| 复合维生素 | 每天随餐 | 通用共识项 |

## 四、训练方案

### 1. 原则

- 三分化（推 / 拉 / 腿），**练三休一**，一次 90 分钟内；
- **组间休息**：主项 3 分钟、辅助 2.5 分钟、孤立 1.5 分钟、核心 1 分钟——ATP 恢复要 3–5 分钟，歇够重量才推得动；
- 主项 12–15 次 × 4 组起步，离心慢、向心快；
- **每次训练记重量**——增肌进步的唯一证据是数字在涨。

### 2. 每个动作练多重 —— 第一次训练先自测（重要）

**人和人差异极大，你的重量你自己测**，10 分钟：

1. 从很轻开始（空杆 / 最小配重）；做 8 次，轻松就加（复合 +5kg、孤立 +1–2.5kg）；
2. 直到**能标准做满 8 次、最后 2 次有点勉强、不变形**——就是你的正确重量；
3. 填进表里，之后递进全部以你填的数为基准。
4. 安全线：加完做不满 6 次或变形，退回上一档。

> 每天末尾都带一个腹部动作——核心是大重量的安全带，也是体型的门面。

### 3. 怎么往上加（渐进超负荷）—— 以你自测的重量为基准

同一个重量：做满 4×8 → 4×10 → 4×12 → **加重量**（复合 +2.5–5kg、孤立 +1.5–2.5kg）→ 回到 4×8 重新爬。

例子：你自测卧推 35kg 做满 4×12 → 加到 40kg，从 4×8 重新开始。

**减载**：每 4 周安排 1 周，组数降到六成，重量维持。减载是"练得少"，不是"随便练"——连续 4 次训练同一个重量做不满 12 次，先减载再说。

### 4. 有氧

增肌期**不做专门有氧**（谭成义原口径：避免额外消耗）——想动就训练后散步 10–20 分钟，促进恢复即可。日常通勤多走路没问题，别安排跑步。

## 五、睡眠与恢复

- 保持 24 点前睡、7.5 小时——肌肉是睡觉的时候长的；
- 睡前 30 分钟放下手机；睡前 4 小时不喝咖啡；
- 训练日晚做 10 分钟腿部 + 下背拉伸。

## 六、执行清单

- **每天**：晨起空腹称重 → 按克数吃（吃不下就上液体热量）→ 训练记重量；
- **每周**：看周均体重 → 按 0.2–0.5% 的标准动碳水 → 拍一张正面照；
- **每 4 周**：减载周 + 量围度（胸/臂/大腿），围度涨了比体重涨了更能说明问题。

## 七、说明

- 本计划为训练与营养参考，不构成医疗建议；有慢性病、用药或伤病史，先咨询医生；
- 执行 4 周后带数据回来，按实际变化出下一版；
- 数字口径：热量盈余 = 凯圣王口径；蛋白/脂肪区间与碳水起步值 = 谭成义《增肌减脂的底层逻辑》；组次递进与减载为训练通用规律；"常见范围"由体型数据推演，仅供起点参考。
