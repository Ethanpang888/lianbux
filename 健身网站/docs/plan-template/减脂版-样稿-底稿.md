# 个人定制 · 减脂训练与饮食计划

> 交付样稿（示例客户：李先生）。实际出售时按买家信息替换全档数字，结构不变。

## 一、你的基本情况

| 项目 | 内容 |
|---|---|
| 性别 / 年龄 | 男 / 30 岁 |
| 身高 / 体重 | 178cm / 85kg |
| 工作状态 | 办公室久坐，通勤地铁 |
| 可训练时间 | 晚 19:30–21:30，每周 3–4 次 |
| 训练经验 | 系统训练 1 年左右，动作基础没问题 |
| 饮食现状 | 工作日多数外卖，周末自己做 |
| 作息 | 24 点前后睡，7 点起，约 7 小时 |
| 目标 | 减脂为主，尽量不掉力量 |

## 二、总体思路

四个字：**缺口小开，力量不丢。**

你的问题不是不够努力，而是热量长期上下浮动——平时外卖超标、周末又想"补回来"，身体一直没拿到稳定的指令。所以这份计划只做四件事：

1. **饮食**：把每天的碳/蛋/脂定成具体克数，执行 7–10 天再动，不天天改；
2. **训练**：力量照练、重量照加——减脂期掉力量的本质是"练轻了、歇短了"，不是"吃多了"；
3. **恢复**：你睡眠本来就不差，只要把睡前那半小时手机管住，恢复效率还能再提一截；
4. **反馈**：每天晨起空腹称重，按**周趋势**调，不看单日波动。

## 三、饮食方案

### 1. 每天吃多少

| 项目 | 数值 | 依据 |
|---|---|---|
| 每日热量 | **2520 kcal** | 按你的体重与活动量估出消耗后，开约 300 的缺口 |
| 蛋白质 | **153g**（约 1.8g/kg） | 取 1.4–1.8 区间上限——减脂期蛋白宁多勿少，保肌肉 |
| 碳水化合物 | **324g**（约 3.8g/kg） | 缺口主要从脂肪砍而不是碳水，训练才有劲；想更激进可在吃满 10 天后降到 290g（3.4g/kg） |
| 脂肪 | **68g**（0.8g/kg） | 不低于 0.8，影响激素水平 |
| 饮水 | **3L/天** | 训练日加 0.5L |

> 用食物秤 + 记录 APP（薄荷健康之类）执行，前两周的目标是"称准"，不是"吃准"。

### 2. 一份减脂餐长什么样

按谭成义的减脂餐结构：**约 80g 碳水 + 45g 蛋白 + 10g 油**，对应到盘子里就是：

- 米饭 200g（生重约 90g）+
- 鸡胸肉 / 瘦牛肉 / 鱼虾 约 200g +
- 烹饪油 10g（一瓷勺）+
- 绿叶菜 200–300g（不计数，管够）

一天 324g 碳水 ≈ 4 份这样的主食，分布在三餐 + 练后。

### 3. 一天怎么排

| 餐次 | 吃什么 | 原因 |
|---|---|---|
| 早餐 | 燕麦 60g + 鸡蛋 2 个 + 无糖豆浆/牛奶 + 少量坚果 | 慢碳稳血糖，蛋白启动合成 |
| 午餐 | 杂粮饭 + 去皮腿肉/瘦牛肉 150g + 绿叶菜 250g | 全天最正式的一餐，蛋白均分利于吸收 |
| 训练前 1h | 香蕉 1 根 | 快碳，保证训练状态（这条别省） |
| 晚餐（练后） | 米饭 150g + 鸡胸/鱼 150g + 蔬菜 | 练后那一顿碳水别怕，它进的是肌肉不是腰 |

### 4. 外卖怎么点（6 条规则）

1. 主食换成**杂粮饭/玉米/红薯**，没有就白米饭过一下水；
2. 蛋白选**去皮**禽肉、瘦牛肉、清蒸鱼，避开红烧、糖醋、油炸；
3. 绿叶菜用开水涮一遍再去掉多余的油；
4. 一顿的蛋白约等于**两个手掌大、一指厚**；
5. 汤面/盖浇饭的汤和酱汁剩到最后，能少喝一半油；
6. 点不到合适的当天，用"即食鸡胸 + 燕麦 + 黄瓜/圣女果"兜底，别用奶茶兜底。

### 5. 补剂（锦上添花，不能替饭）

| 补剂 | 吃法 | 说明 |
|---|---|---|
| 一水肌酸 5g | 每天 1 勺，任意时间，长期吃 | 力量类补剂里证据最足的一个，减脂期帮你保住力量 |
| 乳清蛋白 1 勺 | 蛋白没吃够的餐后补 | 补缺口用的，不是必须 |
| 鱼油 | 随餐 1–2 粒 | 通用共识项 |
| 维生素 D₃ | 早晨 1 粒 | 办公室族普遍缺 |

### 6. 什么时候调、怎么调

先固定吃满 **7–10 天**，只看**晨起空腹的周平均**：

| 情况（连续 1–2 周） | 调整 |
|---|---|
| 周均掉重 < 0.3% | 碳水每天减 30–40g（先减精制碳水），或每天多走 3000 步 |
| 周均掉重 0.5–1% | **不动，这是最好的区间** |
| 掉得比 1% 快、训练力量往下掉 | 碳水加回 30g，缺口开太大了 |
| 晚上饿到睡不着 | 碳水 +30g，从晚餐主食加 |

⚠️ 一次只动一个变量。单次碳水调整不超过 1g/kg，蛋白任何时候不低于 1.6g/kg。

## 四、训练方案

### 1. 原则

- **动作质量 > 重量**：加重量的前提是动作标准、不借力、关节无不适；
- 三分化（推/拉/腿），**练三休一**，一次 90 分钟内练完；
- **组间休息不能省**：主项 3 分钟、辅助 2.5 分钟、孤立 1.5 分钟、核心 1 分钟——力量类训练靠 ATP 供能，它恢复要 3–5 分钟，歇不够练的是疲劳不是肌肉；
- 离心慢、向心快：下放 2–3 秒，推起正常速度。

### 2. 每个动作练多重 —— 第一次训练先自测（重要，别跳过）

**人和人差异极大：有 60kg 的人卧推能推 80，也有 90kg 的新手 40kg 都推不稳。** 所以这份计划不给"标准答案"——你的重量你第一次训练自己测出来，10 分钟的事：

1. **从很轻开始**（杠铃动作从空杆 20kg 起，器械/哑铃从最小配重起）；
2. 做 8 次，轻松 → **加一点**（复合 +5kg，孤立/哑铃 +1–2.5kg），再做 8 次；
3. 重复，直到出现这个感觉：**能标准做满 8 次、最后 2 次有点勉强、动作不变形**——这就是你当前的正确重量；
4. 填进下面的表。之后所有的递进（4×8 → 4×10 → 4×12 → 加重）**都以你填的数为基准**。

> 安全线：加了重量后做不满 6 次、或动作开始变形，退回上一档——那才是你现在的水平，不丢人。

> 每天末尾都带一个腹部动作——核心是减脂期体型的门面，也是大重量的安全带。

### 3. 怎么往上加（渐进超负荷）—— 以你自测的重量为基准

同一个重量，先做满「4×8」→ 慢慢做到「4×10」→「4×12」；**能稳定做满 4×12 就加重量**：复合动作 +2.5–5kg，孤立动作 +1.5–2.5kg，加完回到 4×8 重新爬。

例子：你自测出卧推 40kg 能标准做满 4×12 → 加到 45kg，从 4×8 重新开始。你的数字你做主，这张阶梯对任何重量都成立。

**减载**：每 4 周安排 1 周，组数降到六成（4 组变 2–3 组），重量维持、动作照常。减载是"练得少"，不是"随便练"——它是力量还能继续涨的前提。连续 4 次训练同一个重量都做不满 12 次，就是该减载（或换同肌群主项）的信号。

### 4. 有氧

- 增肌式减脂也要有氧，但**放在力量后面或单独的休息日**，每周 3–4 次、每次 30–40 分钟；
- 想加消耗，**提强度不延时长**：爬楼代替爬坡（上楼两级一起跨，下楼走楼梯护膝）；
- 力量训练前后不要安排超过 10 分钟的有氧——会偷走你的主项状态。

## 五、睡眠与恢复

- 你基础不差，重点抓一条：**睡前 30 分钟放下手机**，卧室全黑；
- 睡前 4 小时不喝咖啡、不吃高糖；
- 训练日晚睡前可以 10 分钟泡沫轴 + 拉伸，针对腿和下背；
- 午休 20–30 分钟（别超过 30 分钟，会进深睡影响晚上）。

## 六、执行清单

**每天**：晨起空腹称重 → 按克数吃 → 训练时录 1–2 个动作视频回看 → 睡前手机放下。

**每周**：固定时间量腰围/胸围/臂围 → 看 7 天平均体重 → 按"第 6 节"决定动不动。

**每两周**：穿短裤拍正面/侧面/背面三张照片，对比体型——体重不动但照片变了，也是进步。

## 七、说明

- 本计划为训练与营养参考，不构成医疗建议；有慢性病、用药或伤病史，先咨询医生；
- 执行 4 周后带数据回来，可以按你的实际变化出下一版；
- 数字口径：宏量区间与饮食结构参考谭成义的减脂体系；组次与重量递进按训练经验通用规律；**起始重量由你第一次训练自测填写**（表中附推演参考范围，仅作没头绪时的起点），之后递进全部以你的自测值为准。
