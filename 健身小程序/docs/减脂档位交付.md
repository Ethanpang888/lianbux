# 减脂档位交付（2026-10-19）

## 功能

更新：独立饮食首页卡片已移除。减脂力度现为两端测评「减脂」目标下的次级选项，饮食页仅在「目标计算与饮食调整」折叠区保留调整入口。详见《目标层级与测评对齐交付》。默认稳步减脂（基准约300大卡缺口），可主动选择强化减脂（基准最高500大卡）；实际缺口均受估算总消耗20%限制。按宏量克数取整后，实际缺口可能略低；界面展示实际数值。

强化档要求有效的成年身体资料、BMI不低于18.5。规则是产品估算，不是谭成义原文处方，不承诺减重速度。持续疲劳、明显饥饿或训练下滑时建议返回稳步档。此基础门槛不是医疗适用性评估。

档位存于profile.fatLossPace，修改档案保留该字段。明确确认切换后清除自定参考目标和旧热量偏移、重新开始7天观察期；保留历史反馈、已吃记录和参考食材份量。已有自定目标在确认切换前继续保留。保存失败回滚，重入和刷新恢复选择。宏观反馈不能继续把实际缺口推过500大卡或20%上限。
