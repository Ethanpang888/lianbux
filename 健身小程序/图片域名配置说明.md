# 动作图不显示？原因与解决办法

## 为什么"只剩文字、图全没了"
小程序里的动作图是从网络 CDN（`https://cdn.jsdelivr.net/...`）加载的。
微信规定：**网络图片域名必须加进小程序后台的「downloadFile 合法域名」白名单**，否则真机/预览一律加载失败——但文字（动作名、要领）照常显示。这正好就是你看到的现象。

> 之前赛普的 GIF 是本地路径（`assets/gif/...`），本地资源不需要白名单，所以当时能动；换成网络图后就必须配域名了。

## 一、立刻看到图（开发阶段，0 成本）
微信开发者工具里：
1. 顶部菜单 **详情 → 本地设置**
2. 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**
3. 重新编译 → 动作图（前后两帧自动循环）就会出现 ✅

## 二、真机 / 正式上线（必须配白名单）
登录 [微信公众平台](https://mp.weixin.qq.com) → **开发 → 开发设置 → 服务器域名 → downloadFile 合法域名**，点「修改」，添加：
```
https://cdn.jsdelivr.net
```
保存后约 5–10 分钟生效，真机即可显示。

⚠️ **重要提醒**：微信要求白名单域名必须有**中国 ICP 备案**。jsDelivr 是境外 CDN，**可能不被后台接受**（提交时若提示"域名未备案"即说明此路不通）。
- 若添加成功 → 直接用，无需改代码。
- 若添加失败 → 见下方"备选方案"，把图迁到合规国内源。

## 三、备选方案（jsDelivr 无法备案时的合规图源）
| 方案 | 说明 | 工作量 |
|---|---|---|
| **CloudBase 存储 `cloud://`** | 你已在用 CloudBase，图片用 `cloud://` 协议引用，**不走域名白名单**，无需备案 | 需把图上传到 CloudBase（可脚本批量上传 444 张） |
| **CloudBase 静态托管** | 默认域名 `*.tcb.qcloud.la` 为腾讯系、已备案，可加白名单 | 上传到静态托管目录 |
| **腾讯云 COS** | `*.myqcloud.com` 已备案，可加白名单 | 建桶+上传 |

> 注：你之前在 CloudBase 控制台看到"设置所有人可读需收费"——那个提示通常是针对**扩容/静态托管**的，存储桶的「所有用户可读」权限本身在免费版是有的。若选 `cloud://` 方案，我可以用脚本批量上传并自动改写 `exercises-data.js` 的图源，你不用手动传。

## 四、已做的代码改进（本版）
- `frame-gif` 组件加了 **加载失败提示**：若图加载不出来，会明确显示"请配置 downloadFile 合法域名：cdn.jsdelivr.net"，不再白屏让你摸不着头脑。
- 顺手修了**器械/居家归类错误**（75 条器械被误标成"无器械"），并在动作卡上加了 **🏠居家 / 🏋器械** 角标，一眼能分清。
