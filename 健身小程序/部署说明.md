# 健身陪伴小程序 · 小白部署指南（个人免费版）

> 目标：不花一分钱，把 `健身小程序/` 跑起来，在手机上能用、能试。
> 本指南**已关闭 AI 答疑**（避免产生费用），**用个人身份注册**（免费、无需营业执照）。
> 每一步都要你亲自点，做到哪一步卡住了，回来告诉我，我陪你走下一步。

---

## 开始前你要准备的 3 样东西
1. 一个**微信号**（就用你日常这个，注册小程序要用它扫码）。
2. 这台 Mac 电脑（已装好）。
3. 网络。

---

## 第 1 步：注册小程序（个人 · 免费）
1. 电脑浏览器打开 → https://mp.weixin.qq.com
2. 点右上角「注册」→ 账号类型选**「小程序」**。
3. 邮箱填一个**没注册过公众号/小程序**的邮箱，收验证码激活。
4. 主体类型选**「个人」**（⚠️ 不是企业、不是个体工商户）→ 填姓名+身份证+微信扫码验证。
5. 注册完成，登录进后台。

✅ **这一步免费**。个人小程序不需要 300 元认证费，也不需要营业执照。
（限制：个人不能接微信支付、不能做电商交易、类目受限——但我们是健身科普+打卡，完全够用。）

---

## 第 2 步：拿到你的 AppID
1. 在 mp 后台左侧菜单 →「开发」→「开发管理」→「开发设置」。
2. 找到「小程序 AppID（AppID(小程序ID)）」，**复制这串字符**存好（形如 `wx1234567890abcdef`）。

---

## 第 3 步：安装微信开发者工具
1. 打开 → https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 下载 **macOS 稳定版**（Stable Build）。
3. 双击安装，打开后用你的微信**扫码登录**。

---

## 第 4 步：导入项目
1. 开发者工具里点「导入项目」。
2. 目录选：`/Users/a1-6/Desktop/健身知识库/健身小程序`
3. AppID：选「填写 AppID」→ 粘贴第 2 步复制的那串。
4. 后端服务：选「**不使用云服务**」（我们待会儿在工具里单独开云开发）。
5. 点「导入」。

⚠️ 导入后编辑器可能报红字说 `YOUR_CLOUD_ENV_ID` 找不到——**这是正常的**，因为我们还没填云环境 ID，下一步就填。

---

## 第 5 步：开通云开发（CloudBase，免费额度）
1. 在开发者工具**顶部工具栏**点「**云开发**」按钮（一朵云的图标）。
2. 第一次会让你「开通」→ 点开通 → 环境名称随便起（如 `fit-prod`）→ 计费方式选「**按量计费**」（有免费额度，测试期基本花不到钱）。
3. 创建后，左上角会显示你的**环境 ID**（形如 `fit-prod-1a2b3c`）。**复制它**。

---

## 第 6 步：把环境 ID 填进代码（只改 1 行）
1. 在开发者工具左侧文件树，打开 `app.js`。
2. 找到第一行（大概是）：
   ```js
   const ENV = 'YOUR_CLOUD_ENV_ID' // ← 替换为你的 CloudBase 环境 ID
   ```
3. 把 `YOUR_CLOUD_ENV_ID` 换成你刚复制的环境 ID，保存（⌘S）。
4. 同时打开 `project.config.json`，把 `"appid": "YOUR_APPID"` 里的 `YOUR_APPID` 换成你的 AppID（如果第 4 步已填可跳过）。

---

## 第 7 步：上传登录云函数
这个云函数用来识别"你是谁"（OPENID），必须部署到云端。
1. 文件树展开 `cloudfunctions/login/`。
2. 在 `login` 文件夹上**右键** →「上传并部署：云端安装依赖」。
3. 等右下角提示「上传成功」。

---

## 第 8 步：建数据库集合 + 安全规则
1. 顶部「云开发」面板 →「数据库」。
2. 点「新建集合」，依次建 4 个（名字一字不差）：
   - `users`（存你的资料+计划）
   - `checkins`（存打卡记录）
   - `planOverride`（你改过的计划）
   - `chat`（AI 对话，暂未用）
3. 每个集合建好后，**点进去 → 权限设置 → 改为「仅创建者可读写」**，或把安全规则贴成：
   ```json
   {
     "read": "doc._openid == auth.openid",
     "write": "doc._openid == auth.openid"
   }
   ```
   （这样只有你自己能看到自己的数据，别人看不到。）

## 第 9 步：在电脑上先跑通（模拟器）
1. 点工具栏「**编译**」▶️。
2. 左边模拟器会出现手机界面：
   - 点「我的」→「去测评」→ 填身高体重目标 → 保存。
   - 回到「今日」看当天训练，展开动作填重量。
   - 「计划」看 28 天表，「记录」看进度条和曲线。
3. 能跑通 = 逻辑没问题。✅

> 模拟器里 GIF 动图能直接显示（电脑不卡大小）。但手机预览/发布对包大小有限制，GIF 那 44MB 必须挪到云端才能上手机——见下面「发布前置」。

2. 如果报错说「包太大」→ 是因为本地 GIF 没搬走，先只在模拟器验证即可，手机版等发布前置做完。
3. 能扫出来正常用 = 圆满。

## 发布前置（想拿链接去抖音/朋友圈宣传时再做）
个人小程序要发出去让人用，必须满足：**主包 ≤ 2MB**。现在 GIF 占 44MB，必须：
1. 云开发控制台 →「存储」→ 上传 `健身小程序/assets/gif/` 整个文件夹。
2. 上传后每个 GIF 会有一个 `https://...` 链接。
3. 把 `utils/kb.js` / `utils/exercises-data.js` 里 `assets/gif/...` 的相对路径，全局替换成对应的 https 链接（这一步我可以写个脚本帮你自动替换，需要时叫我）。
4. 之后「上传」→「提交审核」→ 审核过 →「发布」，拿到正式链接去宣传。

## 第 11 步：部署「每日邮件」定时云函数（订阅后每天 08:00 发训练+饮食）
> 个人小程序无法在微信内主动推送，所以用「邮件」把每天计划发到用户 QQ 邮箱。这一步**可选**，不做也不影响小程序核心功能。

**前置**：第 7 步（login 云函数已部署）+ 第 8 步（users 集合已建）必须先完成，因为发邮件要从 users 集合读订阅用户。

### 1) 部署云函数
1. 文件树展开 `cloudfunctions/sendDailyPlan/`。
2. 在 `sendDailyPlan` 文件夹上**右键** →「上传并部署：云端安装依赖」（会自动装 `wx-server-sdk` 和 `nodemailer`）。
3. 等右下角提示「上传成功」。

### 2) 填发件邮箱凭据（环境变量，不在代码里写死）
1. 云开发控制台 →「云函数」→ 点 `sendDailyPlan` →「配置」→「环境变量」。
2. 新增以下变量并保存：
   | 变量名 | 值 | 说明 |
   |---|---|---|
   | `SENDER_EMAIL` | `你的QQ号@qq.com` | 用来发信的 QQ 邮箱 |
   | `SENDER_AUTH_CODE` | `QQ邮箱授权码` | **不是 QQ 密码**，见下方「怎么拿授权码」 |
   | `SMTP_HOST` | `smtp.qq.com` | 默认即可，可不填 |
   | `SMTP_PORT` | `465` | 默认即可，可不填 |
   | `CLOUD_ENV` | 你的云环境 ID | 如 `cloud1-xxxx`，通常自动识别，可不填 |
3. 保存后**重启该函数**（控制台有「重启」按钮）让环境变量生效。

**怎么拿 QQ 授权码**：电脑浏览器登录 `mail.qq.com` → 设置 → 账号 → 找到「POP3/IMAP/SMTP…服务」→ 开启「IMAP/SMTP 服务」→ 按提示发短信验证 → 拿到一串 16 位授权码，填到 `SENDER_AUTH_CODE`。

### 3) 上传定时器（让它每天自动跑）
1. 回到开发者工具文件树，右键 `cloudfunctions/sendDailyPlan/config.json` →「**上传触发器**」。
2. 提示成功后，云函数会每天 **08:00（北京时间）** 自动触发，给所有「已订阅 + 填了邮箱」的用户发邮件。

### 4) 先测一遍，别直接等明天
在开发者工具「云函数」→ `sendDailyPlan` →「测试」里，用如下参数先跑一次（dryRun 只生成内容不真发，避免 spam）：
```json
{ "dryRun": true }
```
想真发一封到你自己验证：先在小程序「我的 → 每日邮件订阅」里填你的 QQ 邮箱并订阅，然后测试参数填：
```json
{ "test": true, "openid": "你的OPENID" }
```
（OPENID 可在 `users` 集合里该文档的 `_openid` 字段看到。）

> 注意：函数运行时是 UTC，代码已用北京时间手动计算「今天」，所以邮件里显示的「第几天」和你手机 App 里一致；定时器本身的 `0 0 8 * * * *` 是北京时间触发（云开发定时器的时区是北京）。

### 5) 过审相关
`privacy.json` 已声明「收集你的邮箱地址」用途，提交审核时勾选该权限即可，不会因私收邮箱被拒。
