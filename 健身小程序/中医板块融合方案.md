# 中医板块融合方案（设计稿 · 先想清楚再动手）

## 一、核心思路：中医不是新增一个"中医频道"，而是一层"透镜"
不要单独做一个塞满经方的"中医页"。正确做法是把中医原则**映射到现有健身旅程的每一步**。
用户感知会是"这个计划懂我的体质"，而不是"又来一套玄学"。

## 三、融合进现有 5 个 tab 的具体方案

### 1. 测评页 → 加「体质辨识」
- 加 9 种体质简化自测（平和/气虚/阳虚/阴虚/痰湿/湿热/血瘀/气郁/特禀），每题勾选。
- 输出：`体质类型` + `训练宜忌` + `食养原则` → 存进 `profile.tcm`。

### 2. 今日 / 计划页 → 训练宜忌 + 食养（核心感知点）
每个训练日卡片底部加一行「中医贴士」，由 `profile.tcm` 驱动：
- 气虚 → **劳则气耗**：强度 70%，组间多休息，避免力竭
- 痰湿 → **脾主肌肉/痰湿**：有氧为主化痰，忌甜腻生冷
- 阳虚 → **扶阳**：上午练、避寒凉
- 血不养筋 → 练前必拉伸、练后放松

饮食目标点进去，由"吃蛋白"升级为带食养属性：脾虚湿重→山药薏米；阴虚→银耳百合；统一忌冰饮/辛辣。

### 3. 学习页 → 混入中医科普卡
28 张里插中医卡（取材概念库，口语化改写）："为什么练肌肉要先养脾""出汗太多反而伤气""睡前泡脚助恢复"。

### 4. 记录页 → 规则化中医风险提示（不用 AI）
现有规则提示加中医向：连续训练 >5 天未休 → "劳则气耗，建议插一天休息/拉伸"；睡眠打卡差 → "肝藏血，熬夜影响恢复"。

### 5. 新增子页 `pages/tcm/tcm`（像学习/动作库一样从首页进）
- **体质报告**：我的体质 + 训练宜忌 + 食养原则
- **食养方**：按体质给 3–5 个安全食疗方（通用原则，标注"食疗非药，体质偏颇请就医"）
- **经络/时辰**：易筋经拉伸片段（取自 nihaisha `yijinjing`）、子午流注训练时段建议
- **概念卡**：点开概念库词条看白话解释

## 四、tabBar 怎么放（回答"能不能增加"）
微信 tabBar **最多 5 个**（已占：首页/今日/计划/记录/我的）。两种做法：
- **方案甲（推荐先做）**：中医做成**子页**（`navigateTo`），从首页「中医」入口进，不占底栏，体验和 tab 差不多。
- **方案乙（以后想占底栏）**：**替换**其中一个 tab（如把"我的"合并进首页，腾位置给"中医"）。改 `app.json` 的 `tabBar.list` 即可，**随时能换、能改**。

## 五、⚠️ 合规红线（个人小程序尤其注意）
- 个人主体**不能做医疗诊断/治疗**。所有中医内容写"养生科普/传统文化"，加免责声明："仅供参考，不替代医师面诊"。
- 不出现"治疗XX病""调理XX症"等医疗宣称，否则审核会被拒。
- 食疗合集是有版权扫描书，**只提炼通用原则，不复制原文**。
- 倪海厦内容属个人学术观点，标注"参考倪海厦观点，仅供参考"。
