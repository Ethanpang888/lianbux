# GIF / 动作演示图 替换指南

> 目标：把当前本地 `assets/gif/` 里 56 张**赛普健身**（有版权风险）的图，换成可商用的公有领域图，并转成 https URL，彻底消除下架/索赔风险。

## 一、三个图源版权结论（已核实实际许可证）

| 来源 | 许可证 | 可否商用 | 形式 | 备注 |
|---|---|---|---|---|
| **free-exercise-db**（GitHub: yuhonas） | **Unlicense / 公有领域** | ✅ 可，免署名、无限制 | 静态 JPG（非 GIF 动画） | 800+ 动作，最安全。推荐主用 |
| **wger.de** | 动作/食材数据 **CC-BY-SA 3.0**（需署名） | ✅ 可，需注明出处 | 图片多为 Wikimedia 来源 | 另有 **200 万+ 食材营养库**（正好用于补全食物热量表） |
| **Pixabay** | Pixabay License（类 CC0） | ✅ 可，免署名 | 照片/视频为主 | 健身动作 GIF 很少，不建议主用 |

**结论**：动作演示图用 **free-exercise-db**（公有领域，零风险）；食物营养补全可用 **wger 食材库**（CC-BY-SA，在小程序里加一句「营养数据来源于 wger.de」即可合规）。

> ⚠️ 当前 56 张赛普 GIF 只是本地文件、未发布，**目前无暴露风险**，但上线/收费前必须替换。

## 二、「弄全一点」怎么理解（避免瞎下 800 张）

free-exercise-db 有 800+ 动作，但大量是同一动作的细微变式。对本小程序「计划生成」有用的，是覆盖各部位、能被计划引用的**主动作**（复合 + 关键孤立），约 **100–150 个**就足够「全」。建议：
- 先覆盖：胸/背/肩/臂/腹/腿/臀 七大部位的主动作（深蹲、硬拉、卧推、划船、推举、弯举等及其变式）；
- 计划生成器 `utils/kb.js` 的 `FOCUS_SCHEME` 决定每天取哪些部位，动作图只要覆盖这些部位即可。

## 三、最终方案：jsDelivr CDN（免费，无需 CloudBase 付费权限）

**背景**：CloudBase Storage 免费套餐**不允许**把文件权限改为「所有用户可读」，升级付费才能改。为避免提前花钱，我们改用 **jsDelivr CDN** 直接引用 GitHub 上的 free-exercise-db 图片。

- jsDelivr 是免费的公共 CDN，会自动缓存 GitHub 仓库里的文件；
- free-exercise-db 是公有领域（Unlicense），直接外链完全合规；
- **不需要上传 873 张图到 CloudBase Storage**，省掉付费权限这一步。

已完成的自动化工作：

- `assets/exdb/` —— 已下载 **free-exercise-db 整库 873 张**公有领域静态图（本地资产池，一次备齐，未来扩库不用再下）。
- `utils/exercises-data.js` —— 动作库已从 **56 条扩充到 136 条**（原 56 条全部重映射到公有领域 id + 新增约 80 条精选；按部位：手臂20/肩16/背23/胸17/腹21/腿27/臀12）。
- 每条 `gif` 已替换为 jsDelivr URL，格式示例：
  ```
  https://cdn.jsdelivr.net/gh/yuhonas/free-exercise-db@main/exercises/Barbell_Curl/0.jpg
  ```
- `tools/apply-exdb-urls.js` —— 保留脚本，用于后续再次替换（如改用国内付费 CDN 时）。

> 之前误传到 CloudBase Storage `exgif/` 里的 873 张图现在**已不再需要**，可以在控制台里全选删除，避免占用免费存储额度。

## 五、食物营养「补全」怎么做（你问的 300g 羊肉有多少蛋白）

两步走：
1. **立刻可用**：`utils/kb.js` 的 `FOODS` 已扩充（羊肉/鸭肉/猪肉/虾/玉米/南瓜/黑豆…），且「今日」页支持**自定义食物**——用户吃列表没有的，自己写名称+克数，若知道每 100g 营养就填，不知道就只记名称克数（标 `?`）。
2. **彻底补全（推荐）**：用 **wger 200 万食材库**（CC-BY-SA）。我可以下载常见食材的营养数据，生成一份更大的 `FOODS` 表直接内置，覆盖绝大多数中式食材，用户几乎不用手动填。只需在小程序「关于/免责」里加一句「营养数据来源于 wger.de（CC-BY-SA）」。
